Here are the references and a suggested direction for the Skills Scanning project. The project has two parts.

Part 1 — Skill discovery scanner
The idea is to identify repositories that publish their own agent "skills" on public sources (GitHub, GitLab, etc.), rank them in descending order by repo stars, and take the top-N (start with 50, can go up to 100). The scanner then pulls the skills + (other necessary auxiliary) file(s) from those repos so they can be assessed.

Two curated lists are a good starting seed:
- Claude skills: https://awesome-skills.com/
- Antigravity skills: https://sickn33.github.io/antigravity-awesome-skills/

Research goal for Part 1: build a scraper that crawls GitHub, discovers these skills automatically, and produces an exhaustive list. Optimize for throughput (parallelism, rate-limit handling, caching), since GitHub's API is the main bottleneck.

Part 2 — Vulnerability scanning
Two existing open-source scanners are the references to study:
- NVIDIA SkillSpector: https://github.com/NVIDIA/SkillSpector (64 patterns across 16 categories, static + optional LLM analysis)
- Cisco Skill Scanner: https://github.com/cisco-ai-defense/skill-scanner (published threat taxonomy, behavioral dataflow, meta-analyzer for false-positive filtering etc.)

Research goal for Part 2: review both scanners' code, identify gaps, and produce a report plus code improvements. Below is the idea:

1. Cross-scanner analysis: Run both scanners over the same set of skills (the ones from Part 1). Every skill where one scanner flags something the other misses is a candidate gap; then manually inspect a sample of the disagreements to confirm which are real detections vs. noise, and characterize what each scanner catches that the other doesn't. And create a report on the FPs generated by the scanners.

2. Taxonomy coverage analysis: Both repos publish their detection categories. Diff them against each other and against external references such as the OWASP LLM/agentic risks or MITRE ATLAS. Any threat class in the reference that neither scanner detects is a coverage gap.

By these methods you will identify the gaps across the scanners and your goal is to create a written analysis of the gaps in the scanners with how to improve them along with the pseudo code or actual code.
